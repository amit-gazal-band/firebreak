# Firebreak

A live, replayable game that compares how well teams of AI agents coordinate when the only difference between them is how they communicate: Band, sub-agents, Slack, or Linear.

Teams of 5 AI firefighters defend identical copies of a town from spreading wildfires, side by side, on the same seed and clock. Every match is recorded and can be replayed at any speed.
